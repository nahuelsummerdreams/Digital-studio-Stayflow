# Digital Studio brand assets

Vector traces of the Digital Studio logo (source: white-on-black raster supplied by the owner).

| File | Use |
|---|---|
| `digital-studio-logo-white.svg` | Full logo on dark backgrounds |
| `digital-studio-logo-black.svg` | Full logo on light backgrounds |
| `digital-studio-icon-white.svg` | Cube only, dark backgrounds, small sizes |
| `digital-studio-icon-black.svg` | Cube only, light backgrounds |

Rules:
- Digital Studio is the parent brand. Use it as an endorsement ("A product by"), not as an app icon.
- Below ~32px use the cube alone; the wordmark stops being legible.
- Apps copy what they need into their own `public/brand/`.

These are auto-traced from a JPEG. If the original vector file turns up, replace them.

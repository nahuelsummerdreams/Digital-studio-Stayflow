# Embudo de venta

**Anuncio → landing → carrito → pago → gracias → email de acceso → primeros pasos → activación → upsell → soporte → renovación**

| Etapa | Qué pasa hoy | Qué falta |
|---|---|---|
| Anuncio | No hay campañas | Píxel, creativos ([[Anuncios Meta]]) |
| Landing | Embudo alrededor de Host ([[Landing - estructura y copy]]) | Demo en video, prueba social real |
| Carrito | Funciona (localStorage) | — |
| Pago | **No existe** | [[Cobro y licencias]] |
| Gracias + acceso | No existe | Página de gracias, activación de licencia |
| Primeros pasos | Tarjeta de 4 pasos + datos de ejemplo | Emails ([[Email - secuencias]]) |
| Activación | Medible a mano | Métrica en [[Métricas]] |
| Upsell | Repisa y packs en la landing | Email día 3 (Guest/Operations) |
| Soporte / renovación | Selector listo, sin cobro | Mecanismo de renovación |

**Principio:** una promesa, una acción. Host entra primero; lo demás se ofrece después.

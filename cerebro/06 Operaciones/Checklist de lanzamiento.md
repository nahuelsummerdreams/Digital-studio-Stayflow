# Checklist de lanzamiento

## Para cobrar el primer dólar
- [ ] Proveedor de cobro elegido y conectado
- [ ] Pago → licencia activa (webhook) → email de acceso
- [ ] Página de gracias con enlace de acceso
- [ ] Plan de pago de Supabase y respaldos
- [ ] Datos de prueba borrados
- [ ] Páginas legales revisadas + email de contacto

## Para invertir en anuncios
- [ ] ID del Píxel puesto · dominio verificado en Meta
- [ ] Landing de anuncio `/l/host`
- [ ] Video corto de Host
- [ ] Primer producto activado de punta a punta por una persona real
- [ ] Criterio de parada: si en 7 días y USD 50 no hay señal, cambiar el ángulo, no subir el presupuesto
